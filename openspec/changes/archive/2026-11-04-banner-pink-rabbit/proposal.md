## Why

启动画面图标里骑手兔用纯白（256 色 `231`），阴影用浅灰（`250`）。在 VS Code 浅色主题、Windows Terminal 浅色配色这类白底终端上，兔身对白底对比度只有 1.0，整只兔子消失，只剩几粒阴影（Windows 实测截图可见）。0.8.15 起 Windows Terminal 与 VS Code 终端也会画图标，浅色终端的用户更多了。

## What Changes

- 兔身改用樱粉 `211`（#ff87af），兔的阴影改用深一档的 `168`（#d75f87）：兔身对白底对比度 2.2、对 #1e1e1e 深底 7.4，与马的鬃尾（`74`，2.4 / 6.8）相当；粉与天空蓝的马色相分得开。
- 主规格里「兔身 SHALL 用白色 256 色，使两只动物在暗底终端上能分辨」改为用樱粉系，兔与马色相分得开、兔身在深浅底终端上都清楚；场景「马蓝兔白」改为「马蓝兔粉」。
- 不做：改马身、鬃尾、蹄与眼的颜色（马身 `117` 在白底上对比度 1.6，截图里仍可辨认，本次不动）；改字标颜色；按终端背景自动换色；改 `NO_COLOR` 与降级规则。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `rulekit-cli`：「启动画面按终端能力降级」换成「启动画面按终端能力降级与配色」：降级规则不变，兔身由白色改为樱粉系、写明兔身在深浅底上都清楚，场景「马蓝兔白」改为「马蓝兔粉」（OpenSpec 不允许在修改里改场景名，故以删除加新增表达）。

## Impact

- 代码：`src/rulemason/banner.py` 的 `ICON_COLORS` 中 `w`、`g` 两个色号与上方注释；`tests/test_banner.py` 里断言白色 `231` 的用例改为断言 `211`。
- 接入项目：无影响，只是 `rulemason` 交互运行时启动画面的颜色变化。
