rea analyze-javascript-application — Statically reconstruct a local JavaScript/Electron application

Usage: rea analyze-javascript-application <path> [options]

Arguments:
  path  ASAR or extracted application path

Options:
  --detail <complete|summary>                    Deliver complete Evidence, or a summary with --evidence_output (default: complete)
  --evidence_output <string>                     Save complete Evidence as a bundle; required for summary delivery. Never overwrites.
  --view <string>                                JSON javascript-routes view; requires --detail summary and --evidence_output
  --max-semantic-nodes <value>                   Maximum retained semantic nodes across the application; defaults to 100000. Worker heap and parent result admission remain enforced.
  --max-semantic-nodes-per-file <value>          Maximum retained semantic nodes per source file; defaults to 20000, additionally bounded by max_semantic_nodes and memory/transfer limits.
  --max-semantic-unknowns <value>                Maximum retained semantic unknown records across the application; defaults to 100000. Omitted emission occurrences are counted by family and reason.
  --max-semantic-unknowns-per-file <value>       Maximum retained semantic unknown records per source file; defaults to 20000, additionally bounded by max_semantic_unknowns and memory/transfer limits.
  --source-path <array>                          Exact inventoried file path relative to the application root; repeat to select several. No implicit dependencies.
  --source-paths-json <string>                   Inline JSON array or JSON file path of exact inventoried file paths relative to the application root, selected after any --source-path values. Use a file for selections that exceed the host command-line limit.
  --max-heap-mb <value>                          Maximum V8 old-space heap in MiB for the isolated JavaScript source analyzer; defaults to 1024. This does not change the CLI/MCP process heap. When REA runs on Bun, which ignores V8 heap flags, Windows instead limits the analyzer's committed memory to this budget plus a 512 MiB runtime reserve; other Bun hosts enforce no limit.
  --analysis-timeout-ms <value>                  Maximum startup, analysis and transfer time per JavaScript source, in milliseconds; defaults to 300000. On timeout, return collected partial Evidence and stop the analysis.
  --artifact-format <auto|asar|directory>        Application artifact format (default: auto)
  --integrity-policy <fail|record-and-continue>  Behavior when declared application integrity does not match (default: fail)

Custom Global Options:
  --timings  Write measured command timing to stderr.

Global Options:
  --filter-output <keys>              Filter output by key paths (e.g. foo,bar.baz,a[0,3])
  --format <toon|json|yaml|md|jsonl>  Output format
  --full-output                       Show full output envelope
  --help                              Show help
  --llms, --llms-full                 Print LLM-readable manifest
  --schema                            Show JSON Schema for command
  --token-count                       Print token count of output (instead of output)
  --token-limit <n>                   Limit output to n tokens
  --token-offset <n>                  Skip first n tokens of output
