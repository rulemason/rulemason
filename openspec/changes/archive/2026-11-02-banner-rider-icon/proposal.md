# Proposal

## Why

启动画面目前只有块字母字标，没有一个可记的图形。用户在五版像素稿里选定了「兔子骑在奔马背上」（预览方案 B），要把它接进启动画面，让 rulemason 像 Claude Code 的启动行一样有自己的标志。

## What Changes

- 启动画面在 RULEMASON 块字母字标上方加一个 11 行 × 26 列的半格像素图标：一匹向右奔跑的马，背上骑着一只兔。图标与字标之间空一行；字标、版本号、口号、三件事与结尾说明不变。
- 图标用 256 色：马身天空蓝（与字标同色）、鬃尾深一档的蓝、蹄与眼暗灰；兔身白、阴影浅灰、眼睛镂空。
- 图标按现有条件降级：终端窄于 60 列或写不出块字符时，与字标一起换成一行「rulemason 版本号」；设置 `NO_COLOR` 时不输出颜色转义，图标以单色画出。
- 不做：不加动画；不改 init 流程、常用命令表与字标字形；不在 `--help`、`check` 等其他输出里加图标；不往仓库提交任何图片文件；不改 README。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `rulekit-cli`：「交互运行时显示启动画面」加上图标的内容与位置；「启动画面按终端能力降级」加上图标的降级、单色与配色规则。

## Impact

- `src/rulemason/banner.py`：新增图标像素数据、配色与半格渲染；`render` 在字标前拼入图标。
- `tests/test_banner.py`：首行断言从字标改为图标，补图标的颜色、单色与降级用例。
- 图标像素数据由用户提供的两张参考图描出，只以字符网格的形式进入代码；参考图不入库。
- 对接入项目无影响：启动画面只在 rulemason 自己的命令行里出现，`init` / `update` 生成的副本不变。
